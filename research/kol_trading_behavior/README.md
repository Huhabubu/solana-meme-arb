# Solana KOL 交易行为分析

本目录用于独立存放 Solana 链上 KOL（Key Opinion Leader，关键意见领袖）地址的交易行为研究脚本与分析产物。

与仓库现有跨池套利策略代码隔离，不直接修改 `src/` 中的交易策略逻辑。

## 当前脚本

| 文件 | 作用 |
|---|---|
| `分析kol.py` | 从指定钱包历史交易中提取最近 30 个不同代币的最早买入记录，形成 KOL 样本。 |
| `KOL交易历史.py` | 围绕某次 KOL 交易时刻抓取前 30 秒至后 20 秒的代币逐笔成交，用于构造事件窗口。 |
| `获取代币K线.py` | 从 OKX Web3 获取代币历史 K 线，用于分析 KOL 入场后的价格路径。 |
| `获取代币交易历史纪录.py` | 获取代币逐笔历史成交数据，用于更细粒度的交易行为分析。 |
| `代币概览.py` | 获取代币市值、流动性、持币人数、开发者、Bundle/Sniper、风险和社交等特征。 |
| `代币信号追踪.py` | 获取 OKX Meme Radar 的 KOL / Smart Money 信号及相关代币、钱包和流入指标。 |

## 当前分析链路

```text
KOL / Smart Money 信号或指定钱包
        ↓
识别 KOL 地址与交易代币
        ↓
提取 KOL 历史买入样本
        ↓
确定交易时间锚点
        ↓
获取事件窗口逐笔成交 + 历史 K 线
        ↓
补充代币基本面 / 筹码 / 开发者 / 风险特征
        ↓
分析入场时机、后续价格路径、市场冲击、回撤与交易行为
```

## 已知限制

- `获取代币交易历史纪录.py` 当前仍保留原始测试参数，其中 `chainId="56"` 是 BNB Chain，且代币地址和钱包地址写死。用于 Solana KOL 主流程前需要参数化为 `chainId="501"` 及目标地址。
- 当前脚本主要通过 OKX Web3 的网页接口获取数据，接口字段或访问规则变化时可能需要调整。
- 当前各脚本仍以独立函数为主，还没有统一的主程序把整条分析链自动串起来。
- 运行产物（例如 Parquet、JSONL、缓存）暂不提交到仓库，等分析流程确定后再设计输出目录和保留策略。
