## 1. 为什么重做老样本

直接使用 `pnl/token-list` 的最近 Mint 会被阿峰最近几天非常高的交易频率严重占满。即使拉 100 个 Mint，绝大多数仍来自最近 7 天，无法判断 `+1s fast-follow` 是否只是近期行情现象。

因此本轮改用钱包级历史：

`/priapi/v1/dx/market/v2/pnl/wallet-profile/trade-history`

按 `globalIndex + blockTimePagination` 向过去扫描到 30 天边界，从 7–30 天内真实 BUY 记录发现 Mint，再对每个 Mint 使用：

`trading-history/filter-list + userAddressList=[阿峰]`

恢复完整 KOL×Mint 历史，并确认真实首买事件确实发生在 7–30 天区间。

## 2. 采样校正

第一次老样本抽样虽然按 `7–14 / 14–21 / 21–30 天` 分层，但每层内部错误地偏向区间较新的事件，因此该版结果废弃，不作为正式结论。

校正版：

- 钱包历史扫描页数：521 页
- 扫描钱包历史：26,050 条
- 7–30 天内发现独立候选 Mint：3,416 个
  - 7–14 天：1,023 个
  - 14–21 天：800 个
  - 21–30 天：1,593 个
- 每个时间层各抽 80 个候选，共 240 个
- 每层内部按整个时间区间 evenly-spaced 抽样，而不是只取较新端
- 实际发现时间覆盖：
  - 7–14 天：168.12–335.88 小时
  - 14–21 天：336.14–503.98 小时
  - 21–30 天：504.03–719.95 小时
- 最终事件：219
- 分析有效事件：217
- `+1s → hold10s` 有效样本：203
- API / 研究错误：0

## 3. 冻结规则

本轮不根据老样本重新调参。

### Rule A：阿峰 +1s fast-follow

阿峰首笔明显建仓 BUY 出现后：

1. 等待 1 秒；
2. 只使用此时已经发生的数据；
3. 以 `T0+1s` 之后第一笔真实市场成交作为历史参考入场价。

### Rule B：Rule A + 追价 ≤5%

在 Rule A 基础上要求：

`(+1s 参考入场价 / 阿峰首买成交价 - 1) <= 5%`

该 `5%` 条件在本轮老样本之前已经冻结，本轮不修改阈值。

## 6. 阿峰自己的交易表现

老样本：

- 首买 → 首次卖出：n=212，中位 **+15.21%**，胜率 68.4%
- 估算完整清仓轮次：n=159，中位 ROI **+1.29%**，胜率 52.8%

再次说明：阿峰第一次卖出的位置经常不错，但完整交易轮次收益远低于“首买到首卖”这一段价格收益。

## 7. 当前结论

1. **阿峰信号不是最近 7 天才出现。** 校正后的 7–30 天独立历史样本中，`+1s` 跟入后 5–20 秒仍有正中位收益。
2. **优势非常短。** 60 秒持有在三个历史分层均明显恶化。
3. **无条件 Rule A 的 edge 不算巨大。** 老样本 +10s 中位约 +2.98%，真实执行成本可能吃掉相当部分。
4. **Rule B 值得继续，但尚未稳定。** pooled 32 个样本较强，但不同时间层差异明显。
5. **不能直接实盘。** 当前入场价仍是“决策后第一笔真实市场成交”，不是我们以 `$100/$300/$500` 实际下单时的 VWAP。

## 8. 下一步

优先级：

1. 审计极端 MFE / MAE 路径，避免异常成交污染退出规则；
2. 保留固定时点 5/10/20 秒收益作为更稳健的核心指标；
3. 开始构建 `$100 / $300 / $500` 跟单规模的历史可执行 VWAP / 价格冲击近似；
4. Rule A 与 Rule B 参数冻结后继续收集真正未来事件，形成 forward OOS。
